# s17 · Goal Loop

> **格言**：目标决定循环什么时候真正结束 —— 每次准备停止时都由独立判断器审查；目标不可能、执行失败或超过续跑上限时把控制权交还用户

## 学习目标

- 把 `/goal` 实现为会话级的 Stop hook
- 用独立判断器审查"目标是否完成"，而不是让干活的模型自己宣布
- 设计自动续轮的出口：目标不可能、执行失败、超过续跑上限

## 本章要回答的问题

1. 为什么判断器要和干活的模型分开？
2. 好的完成条件应该具备什么特征？
3. 自动继续在什么情况下必须停下，把控制权交还用户？
