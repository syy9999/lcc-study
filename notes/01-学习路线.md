# 01 · 学习路线

> 主线：能动手 → 能做复杂任务 → 能记住和恢复 → 能长期运行 → 能协作 → 能扩展并合体 → 能编排并实现目标闭环。

## 七个阶段

### 阶段一：让 Agent 能动手（s01-s04）

| 章节 | 机制 | 核心问题 |
|---|---|---|
| s01 | Agent Loop | 一个工具 + 一个循环，为什么就够了？ |
| s02 | Tool Use | 如何从 1 个工具扩展到 N 个而不改循环？ |
| s03 | Permission | 工具执行前，谁来决定能不能做？ |
| s04 | Hooks | 如何在不改主循环的前提下插入扩展逻辑？ |

### 阶段二：做复杂任务（s05-s06、s08）

| 章节 | 机制 | 核心问题 |
|---|---|---|
| s05 | TodoWrite | 如何让 agent 先计划再执行？ |
| s06 | Subagent | 如何隔离子任务的上下文？ |
| s08 | Context Compact | 上下文满了，先删什么、后总结什么？ |

### 阶段三：跨会话记忆（s09）

| 章节 | 机制 | 核心问题 |
|---|---|---|
| s09 | Memory | 什么该记、怎么召回、怎么整理？ |

### 阶段四：让任务长期运行（s10-s12）

| 章节 | 机制 | 核心问题 |
|---|---|---|
| s10 | Task System | 如何把大目标拆成可恢复的任务图？ |
| s11 | Background Tasks | 慢操作如何不阻塞 agent？ |
| s12 | Cron Scheduler | 如何让任务按时间自动触发？ |

### 阶段五：多 Agent 协作（s13）

| 章节 | 机制 | 核心问题 |
|---|---|---|
| s13 | Agent Teams | 队友如何通信、认领任务、互不踩踏？ |

### 阶段六：接外部能力并合体（s07、s14-s15）

| 章节 | 机制 | 核心问题 |
|---|---|---|
| s07 | Skill Loading | 知识如何按需加载而不是全塞 prompt？ |
| s14 | MCP Plugin | 外部工具如何并入同一工具池？ |
| s15 | Integrated Harness | 所有机制如何挂回一个循环？ |

### 阶段七：编排与目标闭环（s16-s17）

| 章节 | 机制 | 核心问题 |
|---|---|---|
| s16 | Workflow Runtime | 固定编排如何写进代码并可续跑？ |
| s17 | Goal Loop | 谁来决定循环什么时候真正结束？ |

## 依赖关系

```text
s01 Agent Loop
 ├─ s02 Tool Use
 │   ├─ s03 Permission → s04 Hooks
 │   ├─ s05 TodoWrite
 │   ├─ s06 Subagent
 │   ├─ s08 Context Compact
 │   ├─ s09 Memory
 │   ├─ s10 Task System → s11 Background Tasks → s12 Cron
 │   ├─ s13 Agent Teams
 │   ├─ s07 Skill Loading
 │   ├─ s14 MCP
 │   └─ s15 Integrated Harness
 ├─ s16 Workflow Runtime（独立运行时）
 └─ s17 Goal Loop（独立的小工具池运行时）
```

> 说明：s16、s17 不要求先完成 s15。s16 聚焦固定编排，s17 用更小的工具池讲目标收口。
