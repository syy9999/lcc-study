# 00 · 术语表

> 用自己的话维护这张表。遇到不确定的概念，先在这里补一行，再回去读章节。

| 术语 | 一句话解释 | 章节 |
|---|---|---|
| Agent | 能感知、推理、行动的模型；agency 来自训练，不来自外层编排 | 总览 |
| Harness | 围绕模型的一切：工具、知识、观察、行动接口、权限边界 | 总览 |
| Agent Loop | `messages → LLM → tool_use → 执行工具 → tool_result → 回到 LLM` 的循环 | [s01](../s01_agent_loop/) |
| `messages[]` | 对话状态；包含 user / assistant / tool_result，是模型的全部短期记忆 | [s01](../s01_agent_loop/) |
| `tool_use` | 模型返回的结构化工具调用块（name + input + id） | [s02](../s02_tool_use/) |
| `tool_result` | 工具执行结果，用 `tool_use_id` 与调用配对，作为 user 消息回传 | [s02](../s02_tool_use/) |
| Dispatch Map | `TOOL_HANDLERS = {工具名: 处理函数}`；加工具只加 handler，不改循环 | [s02](../s02_tool_use/) |
| Permission | 工具执行前的放行 / 询问 / 拒绝判断 | [s03](../s03_permission/) |
| Hook | 挂在循环事件上的扩展点，如 PreToolUse / PostToolUse | [s04](../s04_hooks/) |
| Todo | 当前回合内的执行计划，先列步骤再动手 | [s05](../s05_todo_write/) |
| Subagent | 拥有全新 `messages[]` 的子 agent，只把最终文本作为工具结果返回 | [s06](../s06_subagent/) |
| Skill | 按需加载的知识包：system prompt 只放目录，用到时再读完整内容 | [s07](../s07_skill_loading/) |
| Context Compact | 上下文接近上限时的四步压缩：budget → snip → micro → summary | [s08](../s08_context_compact/) |
| Memory | 跨会话保留可复用知识：选择、提取、整理 | [s09](../s09_memory/) |
| Task | 落盘的任务图：状态、依赖 `blockedBy`、owner，可跨会话恢复 | [s10](../s10_task_system/) |
| Background Task | 慢操作交给后台线程，完成后通过通知队列注入结果 | [s11](../s11_background_tasks/) |
| Cron | 按五段式时间表达式触发任务；到期先入队，agent 空闲再交付 | [s12](../s12_cron_scheduler/) |
| Agent Team | 多个持久队友 + 独立循环 + 消息总线 + 任务认领 | [s13](../s13_agent_teams/) |
| Message Bus | 放在模型上下文之外的通信通道，用收件箱事件投递消息 | [s13](../s13_agent_teams/) |
| Worktree | 绑定到任务的独立工作目录，让并行任务互不污染 | [s13](../s13_agent_teams/) |
| MCP | Model Context Protocol；把外部 server 的工具发现并并入同一工具池 | [s14](../s14_mcp_plugin/) |
| Integrated Harness | 把前面所有机制接回同一个 agent loop | [s15](../s15_integrated_harness/) |
| Workflow Runtime | 编排形状固定时写进脚本；单步仍由模型决定，journal 支持续跑 | [s16](../s16_workflow_runtime/) |
| Goal Loop | 模型提出停止，独立判断器按目标完成条件决定是否继续 | [s17](../s17_goal_loop/) |
