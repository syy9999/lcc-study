## 学习目标

- 实现 `PreToolUse` / `PostToolUse` 两类扩展点
- 把 s03 的权限检查迁移成 hook，体会"事件驱动扩展"
- 理解 hook 的上下文、返回值与短路语义

## 本章要回答的问题

1. hook 应该收到哪些上下文？返回什么才能阻止工具执行？
2. 多个 hook 的执行顺序和短路语义是什么？
3. 哪些逻辑适合做成 hook，哪些应该留在主循环里？
