# s11 · Background Tasks

> **格言**：慢操作丢后台，agent 继续思考 —— 后台线程跑命令，完成后注入通知

## 学习目标

- 用线程执行耗时命令，不阻塞 agent 主循环
- 实现通知队列，在合适的时机把后台结果注入对话
- 设计后台任务的完整生命周期：启动、查询、完成、清理

## 本章要回答的问题

1. 什么命令应该走后台？判断依据是什么？
2. 后台完成后，结果如何送回模型？
3. 如何避免结果在错误的时机打断当前回合？
