# s02 · Tool Use

> **格言**：加一个工具，只加一个 handler —— 循环不用动，新工具注册进 dispatch map 就行

## 学习目标

- 从 1 个 bash 工具扩展到多个工具（读、写、编辑、glob、grep 等）
- 用 `TOOL_HANDLERS` 分发，而不是在循环里写一长串 `if/else`
- 正确处理一轮返回多个 `tool_use` 的情况

## 本章要回答的问题

1. 工具定义（JSON schema）和 handler 如何一一对应？
2. 为什么新增工具不需要修改 `agent_loop`？
3. 多个工具调用应该串行还是并行执行？结果如何与调用配对？
