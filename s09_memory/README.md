# s09 · Memory

> **格言**：记住该记的，忘掉该忘的 —— 三个子系统：筛选、提取、整理

## 学习目标

- 实现记忆的三个子系统：selection（选择）、extraction（提取）、consolidation（整理）
- 一条记忆一个文件，按需召回，而不是全部塞进 system prompt
- 让重要信息跨会话保留下来

## 本章要回答的问题

1. 什么信息值得跨会话保存？什么应该丢弃？
2. 召回时如何"先选目录、再加载正文"？
3. 记忆冲突或过期时如何整理？
