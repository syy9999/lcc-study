## 学习目标

- 实现持久队友：每个队友拥有独立的消息列表与循环
- 用 `MessageBus` / 收件箱把通信放在模型上下文之外

## 本章要回答的问题

3. 认领任务与创建 worktree 如何保证并发安全？
